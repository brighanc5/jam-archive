# Help improve The Jam Archive

Contributions should make live-music history more accurate, discoverable and better attributed. Focus on original evidence rather than unsourced summaries.

Please include:

- Artist or project name and known alias, if any.
- Original source URL (official announcement, archive item, original historical database, direct taper documentation).
- Date, venue, city, set slot, and why the proposed correction is necessary.
- If describing a guest musician, whether this is a documented **actual sit-in** versus shared billing, past membership or rumor.
- If a tape, whether it is an audience recording, soundboard-derived source, matrix, or official release, plus known taper and lineage information.
- Rights or attribution requirements and any uncertainty.

We do not upload fan tapes or photos without permission. The eventual public GitHub intake can accept issues through the bundled issue template after a repository is connected. No public submission form or inbox is active yet.

## Proposed review sequence

`new → needs evidence → corroborated → editorially approved → published → periodically rechecked`

A rejection should preserve its rationale so the same unsupported claim is not rediscovered and republished.
