# The Jam Archive

**Free · Fan-built · Source-first.** A map of improvisational music: bands, musicians, historic shows, tapes, and who played with whom. Every claim links back to where it came from, and nothing is hosted that isn't ours to host.

Live at **https://thejamarchive.org**

## Run it locally

```bash
bash scripts/dev.sh     # builds the site and serves it at http://localhost:8000
```

Requires Python 3.11+ and Node. No packages to install, no network needed at build time.

## Contribute

The easiest high-value contribution is a sourced relationship for the Family Tree: add it to [`data/family_tree.json`](data/family_tree.json) with a link that states it. See [CLAUDE.md](CLAUDE.md#adding-to-the-family-tree-the-common-edit) for the format, and [CONTRIBUTING.md](CONTRIBUTING.md) for evidence standards.

For maintainers: [CLAUDE.md](CLAUDE.md) covers the build, deploy flow and conventions. [DATA_RIGHTS.md](DATA_RIGHTS.md) covers sourcing and rights. Older release notes live in [`docs/history/`](docs/history/).

Independent fan project; not affiliated with any artist, venue or archive linked here.
